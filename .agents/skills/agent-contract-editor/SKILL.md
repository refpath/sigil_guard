# Agent Contract Editor

Input: the requested guidance change, affected instructions, Git state, and
existing local discovery entries. Output: useful operational guidance and a chat
summary of decisions, actual validation, and client limitations.

Read [AGENTS.md](../../../AGENTS.md) and the affected skills/standards. Keep
always-on policy in the contract or its owning standard and task procedures in
skills. Consolidate overlapping descriptions and remove aliases with no distinct
workflow. Preserve project terminology and authorization boundaries.

Check current official client documentation before changing discovery or
metadata. Use instruction-only skills and native discovery; preserve local
settings and entries. Names must match directories, descriptions must identify
task/mechanism/stage triggers, and supporting references must resolve.

Validate frontmatter, references, tracking/ignore boundaries, and directory
symlinks with existing tools. Consider representative tasks and adjacent tasks
that should not select a skill. Report this reading-based assessment separately
from any actual client execution. Do not create reports or reusable prompt files.
